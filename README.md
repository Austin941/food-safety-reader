## 📖 專案概述 (Project Overview)

本專案收錄文化大學通識講座《食品安全入門》全系列 17 講之高階互動網頁閱讀器、單元簡報展示系統、完整學術研析報告與 PowerPoint 簡報檔案。

全案以 **米白雅緻 (`#F8F6F0`) 暖調現代極簡風格** 打造，內建 Apple-grade 微互動、KaTeX 數學式渲染、原生 PowerPoint 淡出轉場與響應式閱讀體驗。

## 🖥️ 核心功能特色 (Key Features)

### 1. 高階網頁閱讀器 (`index.html`)
- **Apple-Grade 美學工藝**：以 `#F8F6F0` 暖米白為底，搭配 `#15803D` 森林墨綠、`#C2410C` 陶紅與 `#B45309` 琥珀暖金。
- **KaTeX 數學式排版**：高精度渲染毒理學 $\text{ADI} = \frac{\text{NOAEL}}{100}$ 等公式。
- **即時閱讀指示器**：頂部流暢進度條同步監聽滾動位置。
- **側邊快速切換面板**：一鍵在綜合研析報告與三大單元互動投影片間無縫切換。

### 2. 單元簡報展示系統 (`*.html`)
- **快捷按鍵支援**：
  - `[←]` / `[→]` 或 `[空白鍵]`：前後翻頁。
  - `[F]` 鍵：一鍵進入/退出全螢幕投影模式。
  - `[Home]` / `[End]`：跳至首頁 / 尾頁。
- **分層進場微動態**：卡片以 `cubic-bezier(0.16, 1, 0.3, 1)` 彈簧物理曲線平滑進入。

## 📚 課程研析核心架構 (Curriculum Framework)

### 第一單元：食品中毒之預防（1-1 至 1-6）
- **致病三大機轉**：感染型、毒素型（耐熱毒素煮沸不壞）、中間型對照。
- **六大病原體**：腸炎弧菌（嗜鹽且極怕淡水與熱）、金黃色葡萄球菌（傷口化膿與耐熱腸毒素）、沙門氏桿菌（蛋品家禽需 $> 75^\circ\text{C}$ 全熟）、病原性大腸桿菌（STEC O157:H7 溶血性尿毒症候群）、仙人掌桿菌（炒飯嘔吐型耐熱毒素 vs 肉汁腹瀉型）、諾羅病毒（極低感染劑量，酒精無效需用 1000 ppm 漂白水）。
- **危險溫度帶**：**7°C ~ 60°C** 熱力學邊界與五大黃金原則。

### 第二單元：油品之選擇與安全注意（2-1 至 2-6）
- **油脂化學**：三酸甘油酯結構、SFA、MUFA、PUFA、必需脂肪酸（$\omega$-3, $\omega$-6）。
- **精煉工藝**：脫膠 $\rightarrow$ 脫酸 $\rightarrow$ 脫色 $\rightarrow$ 高溫真空脫臭（精製油發煙點 $> 230^\circ\text{C}$）。
- **換油法定指標**：**總極性化合物 (TPC) $\ge 25\%$** 或 **酸價 (AV) $> 2.0$**。
- **食安真相**：大統棉籽油混油案棉酚迷思科學平反（精煉脫酸後已完全未檢出，罪在攙偽欺詐與銅葉綠素）；苦茶油單元不飽和酸 80% 且發煙點達 252°C。

### 第三單元：認識食品添加物（3-1 至 3-5）
- **安部司肉丸子魔術**：骨邊殘肉重組省思與正面表列三位一體管制。
- **毒理學評估**：NOAEL、100 倍安全係數與 ADI 推導。
- **防腐與物理真相**：酸型 vs 酯型防腐劑；罐頭依法絕對禁止防腐劑；麥當勞漢堡不壞之水分活性 ($A_w < 0.60$) 物理乾燥木乃伊真相。
- **亞硝酸鹽與味精**：肉毒桿菌 vs 亞硝胺生死兩難與抗壞血酸（維生素 C）阻斷解方；味精 (MSG) 世紀冤案平反。

### 跨單元深度前瞻研討
1. 現代外送經濟與雲端廚房的「溫控黑洞」
2. 舒肥法 (Sous-Vide) 的低溫真空厭氧風險評估
3. 「潔淨標章 (Clean Label)」與食品防腐技術的辯證
4. 氣炸鍋高速熱風之膽固醇超氧化物 (COPs) 盲點
5. 抗生素耐藥性 (AMR) 與農畜「健康一體 (One Health)」防線
6. 智慧食安（AI + 微型光譜 + 物聯網）的未來治理願景
